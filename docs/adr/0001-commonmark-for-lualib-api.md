# Use CommonMark for lualib-api docs

The lualib API docs are generated by `lua-language-server --doc` and post-processed by `ConvertTo-DocusaurusDocs.ps1` in the lualib repo. LLS sometimes emits bare Lua `function ...` signatures outside code fences (e.g. `annotations-modules-ogs.mod.md`). Docusaurus v3's MDX loader treats these as JavaScript function declarations and fails the build.

We considered fixing every bare signature in the post-processor, but Docusaurus already supports loading `.md` files as CommonMark while keeping `.mdx` files as MDX. Since the lualib API docs are auto-generated reference material and do not use JSX, CommonMark is sufficient and avoids a fragile regex arms race.

Decision: set `markdown.format: 'detect'` in `docusaurus.config.ts`. This makes all `.md` files in this Docusaurus site CommonMark and all `.mdx` files MDX, exactly matching their extensions.

Status: accepted.

Consequences:
- MDX compilation errors for bare Lua function lines disappear.
- Any future docs written as `.md` will not support JSX/MDX features.
- Any future docs that need JSX must use the `.mdx` extension.
